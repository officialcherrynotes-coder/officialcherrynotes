# 🍒 officialcherrynotes

Welcome to **Cherry Notes** — a simple, aesthetic study materials website for students.

---

## 🌸 About This Project
Cherry Notes is a small student-based digital store that provides:
- 📚 Front page designs  
- ✍️ Full written assignments  
- 🧠 Flashcards  
- 📖 Study materials for school students  

---

## 💡 Purpose
The goal of this project is to:
- Help students get affordable study resources  
- Practice web development skills  
- Build a simple online business idea
